Instalador y scripts transversales viven en:

`database/sqlserver/`

Orden oficial: ver `database/sqlserver/install.sql` y `README.md`.

Scripts por modulo (copias de navegacion):

- `Modulos/Inventario/Database/`
- `Modulos/Compras/Database/`
- `Modulos/Ventas/Database/`
