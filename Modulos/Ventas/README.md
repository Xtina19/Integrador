# Modulo Ventas

POS, facturas, notas de credito y postventa.

**Documentacion oficial:** [`guia/modulos/Ventas/README.md`](../../guia/modulos/Ventas/README.md)

## Estructura

- `Frontend/` — pantallas, componentes, clientes API del modulo
- `Backend/` — ver `Backend/README.md` (codigo runtime o ubicacion documentada)
- `Database/` — ver `Database/README.md` (scripts o nota de esquema)

## Arranque

Frontend via junction `Frontend/src/modules/ventas` → `Modulos/Ventas/Frontend`.
Backend via junction `backend/src/modules/ventas` → `Modulos/Ventas/Backend`.
Apps de arranque: `Frontend/` y `backend/`.
