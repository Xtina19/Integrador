# Backend Importaciones — ubicacion runtime

No existe modulo Express/DDD dedicado de Importaciones bajo `backend/`.

| Pieza | Estado |
|-------|--------|
| Frontend | `Modulos/Importaciones/Frontend/` |
| API FE | `Modulos/Importaciones/Frontend/services/importacionesApi.ts` |

Si se implementa backend, el codigo debe vivir en esta carpeta `Backend/`.
