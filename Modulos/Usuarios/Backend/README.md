# Backend Usuarios — ubicacion runtime

Codigo Express clasico permanece en `backend/` (requires relativos a middlewares/lib/db).

| Pieza | Ruta |
|-------|------|
| Controller usuarios | `backend/controllers/usuarios.controller.js` |
| Controller roles | `backend/controllers/roles.controller.js` |
| Services | `backend/services/usuarios.service.js, roles.service.js` |
| Repositories | `backend/repositories/usuarios.repository.js, roles.repository.js` |
| Routes | `backend/routes/usuarios.routes.js, roles.routes.js` |

Frontend del modulo: `Modulos/Usuarios/Frontend/`
