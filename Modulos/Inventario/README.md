## Estructura

- `Frontend/` — pantallas, componentes, clientes API del modulo
- `Backend/` — ver `Backend/README.md` (codigo runtime o ubicacion documentada)

## Arranque

Frontend via junction `Frontend/src/modules/inventario` → `Modulos/Inventario/Frontend`.
Backend via junction `backend/src/modules/inventario` → `Modulos/Inventario/Backend`.
Apps de arranque: `Frontend/` y `backend/`.
