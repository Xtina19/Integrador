# Backend Auditoria — ubicacion runtime

No existe modulo Express/DDD exclusivo de Auditoria de sistema en `backend/`.

| Pieza | Estado |
|-------|--------|
| Frontend | `Modulos/Auditoria/Frontend/` |
| Inventario (auditoria de stock) | Cubierta por Inventario (`auditoriaInventarioApi` / Engine) |

Si se implementa API de auditoria global, el codigo debe vivir en esta carpeta `Backend/`.
